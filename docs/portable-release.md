Готовый архив Windows 10/11 x64 для запуска без установки и без интернета.

Скачайте **LocalInterfaceWeb-Windows-x64.zip** из Assets, распакуйте в доступную для записи папку и запустите **start-portable.cmd**. Устанавливать Python, PostgreSQL, Node.js, Docker, WSL или включать виртуализацию не требуется. Используется обычная учётная запись Windows. Приложение открывает локальный браузер, пароль администратора показан в окне запуска. Для остановки — stop-portable.cmd.

Внутри PostgreSQL 18.7, Python 3.14.10, зависимости, готовая сборка React и необходимые app-local библиотеки. Программы не регистрируются как системные службы. Пользовательские данные и пароли создаются при первом старте в data/; перед переносом всей папки или извлечением флешки остановите приложение.

Source code.zip/tar.gz — исходники для разработки; они не содержат готовых runtime-компонентов. Проверка SHA256 для готового ZIP находится рядом в файле .sha256. GitHub Actions проверяет свежий запуск, операции с фотографиями, остановку и перенос пути с сохранением БД/изображений.
