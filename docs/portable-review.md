# Проверка автономной Windows версии 14 ноября 2026 года

Цель — запуск на учебном Windows10/11x64 без Docker, WSL, виртуализации, установки программ и сети. Режим использует настоящую PostgreSQL; SQLite остается только дополнительным тестовым режимом.

## Фактическая локальная проверка

- Процесс Windows запущен без повышения прав: WindowsPrincipal.IsInRole(Administrator) вернул false.
- Собраны Python3.14.10 embedded, PostgreSQL18.7 и12 matching Microsoft CRT DLL14.52. Происхождение, SHA256 компонентов/колес, лицензии и файловый manifest сохранены. Installer EXE/MSI не запускались; expand.exe использован только для извлечения CAB при подготовке.
- Реальные модули работающего PostgreSQL VCRUNTIME140.dll/VCRUNTIME140_1.dll/MSVCP140.dll проверены: загружены из runtime/postgresql/bin внутри переносимой папки, системная установка CRT не использована.
- Запуск проверен с PATH только System32, некорректными унаследованными PYTHONHOME/PYTHONPATH/DJANGO/POSTGRES/SQLite параметрами, PIP_NO_INDEX и неработающими внешними HTTP proxy. Launcher изолирует свое окружение, скачиваний или установки пакетов при старте нет.
- Свежая БД, миграции, collectstatic и демоданные созданы автоматически. HTTP smoke PASS: React, миниатюра/полное изображение, CSRF, вход/выход, загрузка, отказ невалидному файлу, поиск Unicode, изменение, замена файла, удаление. Отсутствующие assets/media/API дают404.
- Интерфейс нативной сборки проверен Playwright в Microsoft Edge157.0.4341.46: просмотр, вход, загрузка, поиск, редактирование, удаление и выход; desktop и mobile, ошибок консоли0. Для браузерной проверки использован установленный Edge; Browser plugin отсутствует.
- Повторный старт распознает действующий экземпляр, не создает второй кластер и не завершает первый.
- После штатной остановки папка перенесена в путь с пробелами и кириллицей, запуск повторен: метаданные, оба изображения и вход с прежним паролем сохранились. После финальной остановки принадлежащие установке процессы завершены.
-19 тестов launcher и3 теста извлечения CRT;44 серверных теста, включая10 native HTTP/security проверок, без пропусков. Независимое ревью нативных файлов/сборки/CI не обнаружило блокирующих замечаний.
- Аудит прямых зависимостей portable:0 известных уязвимостей; повторный pnpm audit:0. Точные полные wheel-пины с SHA256 находятся в portable/wheels.json.

## Исправлено по результатам интеграции

Windows PostgreSQL возвращал data_directory с байтами системной кодировки, которые psycopg пытался прочитать как UTF8. После переноса в кириллический путь это останавливало запуск. Вместо текстового пути проверяется бинарная первая строка postmaster.pid: локальная и возвращенная сервером PID должны совпадать с handle собственного дочернего процесса. Добавлены проверки CP1251 и отказа чужому серверу до SQL-изменений. Такая же бинарная проверка используется при штатной остановке.

Дополнительная проверка на англоязычной Windows выявила ограничение PostgreSQL: Win32 API терял символы пути вне системной кодировки. Для каталога с не-ASCII символами запускатель создаёт временное обозначение диска в пространстве текущего пользователя через DefineDosDeviceW. PostgreSQL получает ASCII-пути к собственным файлам, БД и временному каталогу; данные физически остаются внутри приложения. Обозначение удаляется после остановки, а оставшееся после аварии проверяется перед повторным использованием. Занятые диски не заменяются. Оригинальные EXE не изменяются: проверка всех 39 файлов PostgreSQL показала действующие подписи EnterpriseDB. Подход не зависит от наличия коротких имён 8.3, не требует изменения локали, реестра или повышения прав.

Ready URL использует127.0.0.1, чтобы не ждать IPv6 fallback для localhost. Повторное открытие браузера принимает только проверенный loopback URL с явным портом, без userinfo/путей/параметров.

## Поставка и ограничения

Готовый ZIP создается до интеграционных тестов и не содержит data/, паролей или тестовой БД. Исходный Source code.zip из GitHub не является автономной поставкой. Release workflow строит архив на Windows и проверяет свежий запуск/CRUD/перенос до публикации. Статус конкретного релиза виден в GitHub Actions.

Реальная политика учебного учреждения может запрещать запуск любых сторонних EXE — переносимая версия такие ограничения не обходит. Каталог должен быть доступен для записи; перед копированием/извлечением флешки нужно выполнить stop-portable.cmd. Служебные библиотеки включены app-local, но стандартные системные компоненты Windows10/11 по-прежнему необходимы. Публичный сервер/HTTPS и конфиденциальные многопользовательские альбомы не входят в этот локальный режим.
