Проверены все четыре страницы предоставленного WEB_-_Servisy.pdf и тема 12 из списка тем. Документ задает учебные требования; дополнительные технические решения перечислены отдельно. Дата повторной проверки 7 ноября 2026 года.

## Назначение и последовательность работ

| Требование | Реализация |
|---|---|
| Python/Django либо Java/Tomcat | Python/Django |
| PostgreSQL не ниже9.5, ключевая информация в БД | В Compose PostgreSQL17; название, пути и временные метки в photos_photo |
| Предметная область и наполнение | Фотоархив, учебное изображение demo, команда load_demo |
| Инструменты и концепция | Разделы1–2 ПЗ, docs/database.md, README |
| Структура/навигация/страницы или REST API | Каталог, поиск, просмотр оригинала, формы и возврат; API photos/auth/health |
| Поиск через БД | q → нормализация casefold → фильтр PostgreSQL до пагинации |
| Сопровождение и обновление | Миграции, формы изменения, README, резервное копирование |
| Публикация | Исходники https://github.com/arxey/LocalInterfaceWeb, воспроизводимый локальный HTTP стенд; публичный работающий веб-хостинг отдельно не заявляется |
| Тестирование | Django, Vitest, TypeScript/Vite build, HTTP smoke, браузерный сценарий |

## Требования к веб-сервису

| Пункт | Выполнение и границы |
|---|---|
| Единый стиль | Общие CSS, кнопки, поля, состояния, таблица и редактор |
| Opera, Firefox, Chrome, Safari | Реально выполненные browser/engine проверки перечислены в review.md. Движок WebKit не равен нативному Safari; перед защитой нужен проход в требуемых брендированных браузерах |
| HTML/CSS/JavaScript, jQuery/Bootstrap, дополнительные технологии согласуются | React/TypeScript выбраны пользователем. В браузер поставляются HTML/CSS/JS. Применение React/TypeScript следует согласовать с преподавателем; подтверждение согласования не выдумано |
| Сервер Python/Django | Django REST Framework и ORM |
| Минимальное время загрузки | Пагинация10, WebP миниатюры240×160, lazy loading, production build Nginx; глобальный минимум/нагрузочная SLA не заявлены |
| Удобная навигация | Каталог, поиск, страницы, возврат, Escape/клавиатура, явные ошибки |
| Разумное применение таблиц и графики | Настоящая HTML-таблица, миниатюра в списке, оригинал в редакторе |
| Необязательная регистрация/авторизация | Саморегистрации нет; сессия администратора и CSRF защищают запись; гостю разрешено чтение |
| Тестирование известным способом | Автоматические тесты и сквозные сценарии, отчеты и CI |
