## Требования к веб-сервису

| Пункт | Выполнение и границы |

| Единый стиль | Общие CSS, кнопки, поля, состояния, таблица и редактор |
| Opera, Firefox, Chrome, Safari | Реально выполненные browser/engine проверки перечислены в review.md. Движок WebKit не равен нативному Safari; перед защитой нужен проход в требуемых брендированных браузерах |

| Минимальное время загрузки | Пагинация 10, WebP миниатюры 240×160, lazy loading, готовый production build; переносной сервер Waitress/Django либо Nginx в Docker; глобальный минимум/нагрузочная SLA не заявлены |
| Удобная навигация | Каталог, поиск, страницы, возврат, Escape/клавиатура, явные ошибки |

| Необязательная регистрация/авторизация | Саморегистрации нет; сессия администратора и CSRF защищают запись; гостю разрешено чтение |
| Тестирование известным способом | Автоматические тесты и сквозные сценарии, отчеты и CI |

## Способы запуска и переносимость

Переносной Windows-запуск и контейнерный запуск сохраняют один интерфейс, API и модель PostgreSQL. Это дополнительные технические решения; они не подменяют требования методички.

| Условие | Переносной Windows-релиз | Docker-вариант |
|---|---|---|
| Откуда получить | `LocalInterfaceWeb-Windows-x64.zip` из Assets в GitHub Releases | Исходники GitHub, в том числе Code → Download ZIP |
| Поддерживаемая среда | Windows 10/11 x64, обычная учётная запись, доступная для записи папка | Docker с Linux containers и Compose 2.24+ на Windows/macOS/Linux |
| Команды | `start-portable.cmd` / `stop-portable.cmd` | `start.cmd` / `stop.cmd` либо `sh start.sh` / `sh stop.sh` |
| Что уже включено | Python 3.14.10, библиотеки Django/Waitress, PostgreSQL 18.7, собранный React-интерфейс, учебное изображение | Описания образов и сборки; зависимости загружаются при первой сборке |
| Интернет при запуске | Не нужен после получения полного релизного архива | Нужен для первой загрузки образов и пакетов |
| Установка Python/Node.js/PostgreSQL | Не нужна | Не нужна на хосте; нужны Docker и Compose |
| Docker, WSL, права администратора | Не нужны для запуска; правила учреждения на выполнение программ сохраняются | Docker устанавливается и настраивается отдельно; на Windows возможны требования WSL/виртуализации |
| VS Code/PyCharm/pgAdmin | Не нужны для работы; только необязательные инструменты разработки/просмотра БД | Не нужны для работы; pgAdmin включается профилем tools по желанию |
| Локальные порты | Веб 8080, PostgreSQL 55432 либо автоматически выбранные свободные; только 127.0.0.1 | Веб 8080 на 127.0.0.1; БД внутри сети Compose |
| Настройки и пароли | Генерируются в `data/config.json`; пароль администратора выводится локально, существующий не сбрасывается | Генерируются в `.env.docker`; существующий пароль администратора не сбрасывается |
| Сохранение и перенос | После остановки копируется вся папка с `data/`; новая поставка не содержит пользовательских данных | Именованные тома БД/media и `.env.docker`; копии исходников недостаточно |
| GitHub Source code / Code ZIP | Не готов к запуску офлайн: нет runtime и frontend/dist | Подходит для контейнерной сборки при наличии Docker и интернета |
| Инструкция | [docs/portable.md](portable.md) | [README](../README.md#дополнительный-вариант-docker) |

Параметры и пароли обеих установок остаются локально и не публикуются в Git. При переносе работающую БД сначала останавливают; для перехода между основными версиями PostgreSQL применяют экспорт и импорт, а не замену файлов сервера поверх старого каталога данных.
