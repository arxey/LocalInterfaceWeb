# Ревью кода и проверка 7 ноября 2026 года

Проверены все исходники backend и frontend, миграции, management commands, Dockerfile/Compose/Nginx, скрипты запуска, CI и документация. Отдельный независимый проход повторно проверил безопасность и два обнаруженных пограничных дефекта. Ревью относится к этой версии проекта и не является гарантией отсутствия всех ошибок.

## Найдено и исправлено

| Проблема исходной версии | Исправление и доказательство |
|---|---|
| Анонимные создание/замена/удаление | Session authentication, IsAuthenticatedOrReadOnly, тесты403 |
| Отсутствие защиты входа и мутаций от CSRF | Защищенный login/logout и DRF SessionAuthentication; отдельный клиент с enforce_csrf_checks |
| Предсказуемый секрет и DEBUG=1 по умолчанию | Секрет обязателен, DEBUG=0; launcher создает случайные секреты |
| Изображение частично записывалось до ошибки обработки | Предварительное декодирование, транзакция и компенсация новых файлов |
| Старые файлы удалялись до commit | Удаление через on_commit, rollback регрессия |
| Не было лимита декодированных пикселей/анимации | 25MP, статические JPEG/PNG/WebP,10MiB, нормализация/метаданные/UUID |
| Admin обходил pipeline API | Общая модельная обработка файлов и удаления |
| Старая модель могла восстановить пути удаленных файлов после параллельной замены | Блокировка строки и сохранение текущих файлов без новой загрузки; независимая репродукция и регрессия |
| Unicode casefold переполнял varchar120 | search_title360; исправлен порядок старого backfill и новый полный пересчет, миграционные тесты PostgreSQL |
| Частичное сохранение названия не обновляло поиск | Автодобавление search_title к update_fields |
| Некорректные JSON/NUL/слишком длинный поиск | Контролируемые400, ограничение длины и проверка типов |
| Старые ответы/двойные действия/ложный пустой каталог | Abort guards, защита повторных запросов, retry и восстановление пагинации |
| Диалог не удерживал/возвращал фокус | Focus trap, Escape, inert, блокировка закрытия во время сохранения |
| Запуск зависел от локального npm/Node/PATH | Docker+Compose, платформенные launchers, генерируемый env |
| Gunicorn пытался создать служебный сокет в недоступном home | Документированный --no-control-socket; Compose управляет жизненным циклом |
| Известные уязвимости пакетов | DRF3.18.2, Pillow13, Vite6.4.5, Vitest4.1.12, обновленный lock |
