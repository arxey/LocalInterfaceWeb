# Переносимый запуск и проверка безопасности

Цель: привести существующий фотоархив темы 12 к методическим требованиям, устранить обнаруженные дефекты и опубликовать исходники в arxey/LocalInterfaceWeb.

Сохраняются Django, Python, PostgreSQL, React и TypeScript. Интерфейс: таблица фотографий с миниатюрами, просмотр оригинала, поиск, создание, редактирование и удаление. Данные существующей установки в Downloads не меняются.

Выбран Docker Compose: установленный Docker Desktop или Docker Engine с Compose является единственным обязательным инструментом пользователя. Альтернатива с ручной установкой Python/Node/PostgreSQL сохраняется для разработки; переносимая SQLite-версия не отвечает методичке. Windows start.cmd, macOS/Linux sh start.sh генерируют секреты, собирают контейнеры, запускают миграции и демоданные. Сервис доступен только на loopback, порт 8080; pgAdmin опционален.

Чтение фотографий публичное внутри локальной установки, изменения требуют сессии администратора и CSRF. Учетная запись и пароли создаются автоматически и хранятся в исключенном из Git .env.docker. Никаких универсальных паролей, реального .env, пользовательских фото или среды IDE в публикации.

Загрузка: статические JPEG/PNG/WebP до 10 МиБ, ограничение декодированных пикселей, проверка содержимого, безопасные имена, миниатюра до 240x160. Ошибка обработки не должна оставлять поврежденную запись; удаление старых файлов после подтверждения транзакции. Нужны тесты авторизации, CSRF, ошибочных загрузок и жизненного цикла файлов.

Проверка: PostgreSQL integration, backend regression tests, frontend tests/build/audit, Bandit/pip-audit, браузерные сценарии, CI чистого Compose старта и сохранности данных при перезапуске. Документация содержит точную матрицу методички и честные ограничения проверок. Публикация исходников GitHub не объявляется публичным веб-хостингом.
